How the verdict works

  • One run per PR and head commit.
  • Four specialists give one verdict each: Code Risk, Quality, AI Trust and Metrics.
  • Every check has to pass. Any missing, failed or malformed check means HOLD.
  • A required check that the CI path filter skips is fine when the PR doesn't touch that code.
  • If an AI verdict disagrees with CI, both sides go to Shaun.
  • Only Code Risk gives a confidence number. It's the model's own judgement and isn't calibrated; the fixed gates decide the verdict.
  • No agent merges or deploys. Only Shaun approves a merge.
